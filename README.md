# Python Number Guessing Game

## Description
A simple command-line game built with Python. The computer generates a random number between 1 and 100, and the player tries to guess the correct number.

## Features
- Generates a random number between 1 and 100.
- Provides hints when the guess is too high or too low.
- Validates user input.
- Counts the number of attempts.
- Allows the player to play again.

## Technologies Used
- Python
- Random module
- Functions
- Loops and conditional statements
- Exception handling

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python number_guessing_game.py
```
